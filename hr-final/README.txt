Страница "HR / Команда" (раздел БУП, kb.severstal.com, пространство Силовые Машины)

ЧТО ВСТАВЛЯТЬ (сверху вниз)
Страница в Confluence | Порядок | Что вставить
----------------------+---------+----------------------------------------------------------------
HR / Команда          | 1       | макрос HTML <- файл 1-hr-hero.html (тёмный hero + блок миссии)
                      | 2       | макрос HTML <- файл 2-hr-cbl-open.html (метка "Практики" + открывающий div)
                      | между   | НАТИВНЫЙ макрос "Содержимое по меткам" (Content by Label):
                      |         |   метка: см_персонал; отображать как: список
                      | 3       | макрос HTML <- файл 3-hr-cbl-close.html (закрывающий div)

ШАГИ ВСТАВКИ
1. Открыть страницу на редактирование и удалить старые макросы (в т.ч. старый "Содержимое по меткам").
2. Вставить макросы HTML 1 и 2; в каждый скопировать целиком содержимое своего файла.
3. Под макросом 2 вставить нативный макрос "Содержимое по меткам" (метка см_персонал), под ним - макрос HTML 3 (файл 3-hr-cbl-close.html, содержимое: </div>).
4. В файле 1 заменить URL_PLACEHOLDER_STARTOVAYA на адрес стартовой страницы БУП (текст целиком). Сохранить.

ВАЖНО
- Макрос 2 открывает div, макрос 3 закрывает - нельзя вставлять только один из них. Если после сохранения линии между строками списка пропали - проверьте, что макрос 3 стоит ПОСЛЕ нативного макроса.
- Нативный макрос в HTML-макрос вставить нельзя - поэтому блок состоит из трёх частей.
