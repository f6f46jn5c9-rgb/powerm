Как обновить страницу (4 шага)
1. Откройте страницу «Лучшие практики проектов» на редактирование (карандаш).
2. Удалите все старые макросы HTML на странице.
3. Вставьте новые по порядку: добавьте макрос HTML, откройте файл 1-shapka.html в блокноте, скопируйте всё содержимое целиком (Ctrl+A, Ctrl+C), вставьте в макрос. То же для файлов 1a, 2 и 3, каждый в свой новый макрос HTML, сверху вниз.
4. Нажмите «Опубликовать».

Если страница уже собрана и нужно добавить только приветствие
Чтобы добавить только приветствие: откройте страницу на редактирование -> поставьте курсор между шапкой и блоком «Программа ДБВ» -> вставьте HTML-макрос и код из файла 1a-privetstvie.html -> сохраните.

Важно
- На странице должно быть ровно 4 макроса. Другие макросы в эти блоки вставлять нельзя.
- Файлы правьте только вместе с разработчиком: они собраны автоматически.
- Посмотреть результат без Confluence: откройте preview/index.html двойным щелчком (интернет не нужен).

Состав архива: файлы для вставки (4 шт.), README.txt, preview/ (index.html, bp.html), screens/ (снимок страницы).
