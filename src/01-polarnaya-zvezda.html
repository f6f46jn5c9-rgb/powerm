1

Навигация по системе

Полярная звезда — веб-система. Откройте браузер и перейдите на ursulita.ru. После входа в систему вы увидите боковое меню с разделами.

Основные разделы, с которыми работают участники ДБВ:

  • Цели — стратегические цели организации
  • Инициативы — крупные инициативы и программы
  • Портфель — все проекты с иерархией (приоритет → программа → проект)
  • Метрики — KPI и ключевые показатели
  • Активы — загрузка и просмотр документов
  • Реестр мероприятий — план мероприятий по проектам
Совет: Большинство повседневных задач выполняется через раздел Портфель.
2

Портфель проектов — главный экран

Раздел Портфель — центральное рабочее пространство. Здесь отображается иерархия: Приоритет → Программа → Проект → Мероприятие.

На этом экране вы можете:

  • Раскрыть/свернуть уровни — кликните стрелку слева от названия строки
  • Фильтровать — используйте фильтры вверху (по статусу, ответственному и т.д.)
  • Открыть карточку — кликните по названию проекта
  • Действия с проектом — правый клик мышью по строке (см. раздел 3)
Цветовые индикаторы статуса: зелёный = активен / в норме, жёлтый = под риском, красный = критический, серый = завершён.
3

Контекстное меню: как добавить проект / открыть отчёт

Для большинства действий с проектом используется контекстное меню — оно открывается по правому клику мыши на строке.

Доступные действия в меню:

Пункт менюЧто делает
ДосьеОткрывает карточку проекта в режиме просмотра
РедактироватьОткрывает форму редактирования полей проекта
ОтчётОткрывает форму создания отчёта о прогрессе
КопироватьСоздаёт копию проекта
Добавить цельПривязывает стратегическую цель к проекту
Добавить мероприятиеДобавляет мероприятие в рамках проекта
Импорт мероприятийМассовый импорт мероприятий из файла
Важно: Пункт «Удалить» необратимо удаляет проект. Используйте его только при уверенности и согласовании с администратором.

Как добавить новый проект или программу:

  1. 1Найдите родительскую строку — программу, к которой хотите добавить проект
  2. 2Правый клик по строке программы → откроется контекстное меню
  3. 3Выберите «Добавить проект» или соответствующий пункт
  4. 4Заполните поля в открывшейся форме (см. раздел 4)
4

Карточка проекта — поля для заполнения

Форма «Редактирование проекта» открывается через контекстное меню → «Редактировать». Заполните поля карточки и нажмите «Сохранить».

ПолеОписаниеОбязательность
НазваниеПолное название проектаОбязательно
КодКраткий идентификатор проекта (латиница/цифры)Обязательно
ОписаниеПодробное описание проекта (поддерживает форматирование)Желательно
РуководительОтветственный за проект — выбор из справочникаОбязательно
СпонсорКуратор/спонсор проекта — вводится e-mailПо необходимости
Дата началаПлановая дата старта проектаОбязательно
Дата окончанияПлановая дата завершенияОбязательно
СтатусАктивен / Завершён / Приостановлен / ОтменёнОбязательно
Тип реализацииКлассический / Agile / Гибридный и др.По необходимости
Подсказка: Вкладки «Информация» и «Комментарии» в нижней части карточки позволяют добавить дополнительные сведения и оставить заметки.
Сохранение: Нажмите кнопку «Сохранить» внизу формы. Для отмены изменений — «Отмена» или кнопку ✕ в углу.
5

Отчёт о прогрессе — как создать и заполнить

Отчёт о прогрессе позволяет зафиксировать текущее состояние проекта. Создаётся через контекстное меню → «Отчёт» на строке проекта.

  1. 1Правый клик по строке нужного проекта в разделе «Портфель»
  2. 2Выберите «Отчёт» в контекстном меню
  3. 3Заполните форму — секции можно разворачивать по одной кликом
  4. 4Нажмите «Сохранить» — отчёт будет доступен в истории проекта

Заголовок формы:

ПолеОписание
Дата отчётаДата составления — выбор из календаря
Статус отчётаЧерновик (по умолчанию) → Опубликован после финализации

Секции отчёта (открываются кликом по заголовку):

СекцияЧто заполнять
Управленческое резюмеКраткое резюме для руководства — поддерживает форматированный текст
Успехи и достиженияЧто было выполнено за период
Уроки и блокираторыПроблемы, риски, извлечённые уроки
Операционные метрикиЧисловые показатели эффективности
Прогресс трансформацииАвтозаполнение из данных системы
РесурсыСведения о ресурсах: бюджет, команда
Обратная связь заказчикаОценка заказчика (Нейтральный / Одобряющий / Критический)
КомментарииДополнительные заметки в свободной форме
Черновик vs. Опубликован: Пока статус «Черновик» — отчёт виден только вам. Смените статус на «Опубликован», чтобы руководство могло его увидеть.
6

Активы — документы проекта

Раздел «Активы» (боковое меню) — хранилище документов, привязанных к проектам: презентации, протоколы, планы, прочие файлы.

  • Загрузить документ — кнопка «Добавить» в правом верхнем углу
  • Привязать к проекту — при загрузке укажите нужный проект из справочника
  • Поиск по названию — строка поиска в верхней части таблицы
7

Метрики — ключевые показатели

Раздел «Метрики» отображает KPI и целевые показатели, привязанные к проектам и целям. Используется для мониторинга прогресса в числовом выражении.

Каждая карточка метрики показывает:

  • Название и единицу измерения
  • Текущее значение vs. целевое
  • Процент выполнения
  • Привязку к проекту/цели
Обновление метрик происходит автоматически на основе данных, внесённых в карточки проектов и отчёты о прогрессе.
