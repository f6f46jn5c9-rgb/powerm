СТАРТОВАЯ СТРАНИЦА БУП «СЕВЕРГРУПП» — СТИЛЬ «КАРМИН»
Site Home сайта Refined (Confluence DC 9.2, Refined 7.9, Layout Editor), kb.severstal.com/site/BSS

Три варианта на выбор. На странице ставится ОДИН вариант: все его модули по порядку.
Каждый модуль — самодостаточный фрагмент (стили + разметка + скрипт) для HTML Module (Refined).
Модули адаптируются к ширине СВОЕЙ колонки (container queries), а не окна, поэтому
широкое/узкое дерево страниц, масштаб 125–150 % и будущая панель Нейрона не ломают вёрстку.
Картинок нет: фактуры и свечение — CSS, иконки — встроенный SVG.

Важно:
  • Замену баннера Navigation Highlight HTML-шапкой согласовать с владельцем БУП.
  • Шрифты Manrope/Inter можно подключить через тему Refined — до этого будет Arial.
  • Штатный Footer Refined не трогаем.
  • В Layout Editor каждая секция — ОДНА колонка на всю ширину. Внутренние колонки делает сам модуль.

2. CONFIG — ЧТО ЗАПОЛНИТЬ
----------------------------------------------------------------------
В начале скрипта КАЖДОГО модуля есть объект CONFIG. Он одинаковый во всех модулях.
Если что-то меняете — поменяйте одинаково во всех модулях страницы.
Значение "TODO" или "[…]" = «не заполнено»: такая ссылка не выводится (плитка скрыта
или пункт показан обычным текстом «ссылка уточняется»), список незаполненного пишется в консоль браузера.

  Поле                         | Сейчас                  | Что сделать / откуда взять
  -----------------------------+-------------------------+-----------------------------------------------------------
  searchPageUrl                | /dosearchsite.action?…  | проверить адрес полной страницы поиска kb.severstal.com
                               |                         | (открыть поиск, скопировать адрес до текста запроса)
  replicatedLabel              | "TODO"                  | метка тиражируемых практик — уточнить у администраторов.
                               |                         | Когда заполнена, сами появятся вкладка «Тиражируемые» (1К, 2К)
                               |                         | и полка «Тиражируют чаще всего» (6К)
  popularQueries               | ["[запрос 1]", …]       | 3–6 частых запросов для строки «Часто ищут:» (пока строка скрыта)
  stats.activeUsers            | null                    | число «Активных пользователей» из текущего счётчика (null — плитка скрыта)
  stats.practicesManual        | null                    | запасное число «Опубликованных практик», если запрос к API не прошёл
  featured[…] «Материалы       | "TODO"                  | адрес страницы (пока плитка скрыта)
   конференций», «Эксперты     |                         |
   академии»                   |                         |
  featured «Видеопроект»       | страница «Извлечённые   | проверить, что это нужная страница
                               |  уроки (новое видео)»   |
  links.actions «Подать заявку | "TODO"                  | адрес формы заявки (пока кнопка скрыта)
   на редактирование базы»     |                         |
  links.more (6 пунктов)       | "TODO"                  | «Посмотреть все практики», «Дайджест производственных практик»,
                               |                         | «Библиотека Бизнес-системы», «Экспертные сообщества «Севергрупп»»,
                               |                         | «О команде проекта», «Связаться с администратором»,
                               |                         | «Отправить запрос на информацию…» — адреса страниц/форм
                               |                         | (пока показаны текстом «ссылка уточняется»).
                               |                         | Первый пункт («Посмотреть все практики») — ещё и ссылка «Все практики»;
                               |                         | пока он пуст, «Все практики» ведёт на страницу метки /label/BSS/практика
  newsCql                      | все блог-посты          | при желании сузить: type = blogpost AND space = "BSS" ORDER BY created DESC
  shelves (6К)                 | 4 полки                 | можно добавить полки других компаний (ancestor = pageId компании),
                               |                         | enabled:false — полка не выводится
  effectFromExcerpt (6К)       | false                   | true — на карточках полок показывать «было → стало» из текста практики
                               |                         | (строка вида «было 45 мин → стало 12 мин»)

Уже заполнено (реальные ссылки): addPracticeUrl (форма Allforms), neuronUrl (страница «Нейрон БСС»;
текст запроса туда не передаётся), categoriesUrl («Фокус на лучшем. Итоги базы»), 5 компаний с pageId,
12 разделов, 4 материала, Synapse, частые вопросы, техподдержка, practiceLabel = "практика".

Откуда берутся данные (запросы к REST API того же сайта, под учёткой пользователя):
  • новые практики — label = "практика" ORDER BY created DESC (по дате СОЗДАНИЯ: правка старой практики её не поднимает);
  • компания практики — по предкам страницы (pageId компании из CONFIG.companies);
  • новости — 5 последних блог-постов (newsCql);
  • «Опубликованных практик» и «Новых за неделю» — число результатов поиска;
  • «Компаний группы» — число компаний в CONFIG.
Если API не ответил — показываются ссылки «Все практики», «Все новости», «Поиск по базе»; выдуманных данных нет.


3. ПОРЯДОК УСТАНОВКИ
----------------------------------------------------------------------
  1) На тестовом сайте Test04: Site Home → Edit → Import/Export → Export (резервная копия раскладки).
  2) Убедиться, что HTML Module включён:
     Refined Administration → сайт → Configuration → Security → Enable HTML module.
  3) Удалить Navigation Highlight и ряды с несколькими колонками; создать секции в ОДНУ колонку
     (по числу модулей варианта: 4 для 1К, 3 для 2К и 6К).
  4) В каждую секцию: Add Module → HTML Module → вставить содержимое файла целиком, по порядку из п. 1.
     Footer не трогать.
  5) Заполнить в CONFIG всё, что помечено TODO (таблица п. 2), — одинаково во всех модулях страницы.
  6) Publish → проверить на ноутбуке (масштаб 100/125/150 %, дерево узкое/широкое) и с телефона.
  7) Переносить на боевой сайт только после проверки на Test04.

Если Refined режет содержимое секции (overflow: hidden) — список подсказок поиска всё равно виден:
он раскрывается внутри шапки и сдвигает содержимое вниз, а не «висит» поверх соседних секций.
