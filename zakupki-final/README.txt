Страница "Закупки. Силовые машины" (Тип А) -> 1 HTML-макрос (файл 1-zakupki-hub.html: шапка + 5 секций, 16 плашек).

ВСТАВКА В CONFLUENCE (4 шага)
1. Открыть страницу на редактирование (kb.severstal.com, пространство BSS, Силовые Машины).
2. Удалить старые HTML-макросы со страницы.
3. Вставить макрос HTML и скопировать в него целиком содержимое файла 1-zakupki-hub.html.
4. Сохранить и проверить страницу.

КАК ДОБАВИТЬ АДРЕСА ПОЗЖЕ
Сейчас все 16 плашек показывают "Скоро". Когда страница готова:
1. Найти в репозитории powerm файл src/zakupki/zakupki-pages.js.
2. Вписать адрес в нужное поле, например:  dogovor: 'https://kb.severstal.com/spaces/BSS/pages/ID/',
   (hub - адрес самого хаба, bup - крошка "БУП", уже заполнена).
3. Выполнить:  python3 tools/build_zakupki.py   (результат: dist/zakupki-hub.html)
4. Перезалить файл: заменить содержимое HTML-макроса на странице новым dist/zakupki-hub.html (или zakupki-final/1-zakupki-hub.html после копирования).
Плашка с адресом становится активной ссылкой автоматически, HTML править не нужно.
