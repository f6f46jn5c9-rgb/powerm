СТРАНИЦА «ПОЛЕЗНЫЕ МАТЕРИАЛЫ ПРОГРАММЫ ДБВ» (Confluence, kb.severstal.com, пространство БУП)

Что внутри: один HTML-макрос (файл 1-materialy-menu.html). Он сам читает вложения страницы и строит выпадающее меню из трёх разделов:
  1. Записи обучающих вебинаров (видео);
  2. Обучающие материалы (названия, начинающиеся с «Актив проекта» или «Вопросы для самопроверки»);
  3. Презентации выступлений (всё остальное).
Названий файлов в коде нет: что загружено во вложения, то и появится на странице. Пустой раздел не показывается.

ШАГ 1. ЗАГРУЗИТЬ ФАЙЛЫ НА СТРАНИЦУ
1. Откройте страницу «Полезные материалы программы ДБВ».
2. Нажмите «…» (Инструменты) -> «Вложения».
3. Нажмите «Загрузить файлы», выберите файлы (можно перетащить мышью в окно).
4. Нажмите «Загрузить».

ШАГ 2. ВСТАВИТЬ МАКРОС
1. Откройте страницу на редактирование (карандаш).
2. Добавьте макрос «HTML» (набрать «/html» или Вставить -> Другие макросы -> HTML).
3. Откройте файл 1-materialy-menu.html в Блокноте, выделите всё (Ctrl+A), скопируйте (Ctrl+C), вставьте в макрос (Ctrl+V).
4. Нажмите «Сохранить» / «Опубликовать».

ШАГ 3. ПРОВЕРИТЬ
Откройте страницу. Должны быть три раздела (по умолчанию закрыты; если файлов только в одном разделе, он открыт сразу). Раскройте каждый, нажмите на несколько названий: файл должен открыться или скачаться. Рядом с названием раздела стоит число файлов.
Если вместо списка написано «Список файлов не загрузился. Откройте вложения страницы» — нажмите на эту ссылку и проверьте, что вложения есть и у вас есть право их просматривать.

КАК ПОМЕНЯТЬ РАСПРЕДЕЛЕНИЕ ПО РАЗДЕЛАМ
В начале скрипта (внутри файла, после слов <script> и «ПРАВИЛА РАСПРЕДЕЛЕНИЯ») есть блок RULES. Одна строка = одно правило:
  { sec: 0, ext: ['mp4', 'mov', ...] }                          видео -> раздел 0 (Записи обучающих вебинаров)
  { sec: 1, start: ['актив проекта', 'вопросы для самопроверки'] }   название начинается с ... -> раздел 1 (Обучающие материалы)
  { sec: 2 }                                                    всё остальное -> раздел 2 (Презентации выступлений)
Работает первое подошедшее правило сверху. Чтобы добавить в «Обучающие материалы» ещё одну группу файлов, допишите начало названия строчными буквами в список start. Последнюю строку { sec: 2 } всегда оставляйте последней. Названия разделов — в строке SECTIONS ниже. После правки сохраните страницу.

ЕСЛИ ФАЙЛ НЕ ВЛЕЗАЕТ В ЛИМИТ ВЛОЖЕНИЙ
Видео обычно самые большие. Максимальный размер вложения задаёт администратор Confluence. Если загрузка отклонена, обратитесь к администратору или сожмите видео. Ссылки на видео во внешних хранилищах этот макрос не показывает: он берёт только вложения этой страницы.

ЧТО ПРОВЕРИТЬ НА СТРАНИЦЕ-КОПИИ СНАЧАЛА
1. Создайте копию страницы, на копии выполните шаги 1-3.
2. Убедитесь, что список появляется: макрос читает вложения через адрес /rest/api/content/<номер страницы>/child/attachment. Если вместо списка ошибка, значит REST API заблокирован политикой сайта или у читателя нет доступа к вложениям — сообщите администратору.
3. Проверьте под учётной записью обычного сотрудника (не автора страницы).
4. Проверьте, что ссылки на файлы открываются, а на странице один HTML-макрос.
5. Только после этого повторите на основной странице.

ПРЕВЬЮ БЕЗ CONFLUENCE
Откройте preview/index.html двойным щелчком (интернет не нужен). Список файлов в превью — ТЕСТОВЫЕ данные (названия и размеры придуманы для проверки); на реальной странице список берётся из вложений. Вверху превью переключатель ширины колонки: 1100 / 820 / 560 / 375.
