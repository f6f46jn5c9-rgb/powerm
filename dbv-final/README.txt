КАК ЗАМЕНИТЬ СОДЕРЖИМОЕ СТРАНИЦЫ (для каждой из 6 страниц)

Шаг 1. Откройте страницу в Confluence и нажмите «Редактировать».
Шаг 2. Удалите все старые макросы HTML на странице (выделите макрос, нажмите Delete).
Шаг 3. По порядку вставьте новые макросы HTML: для каждого файла добавьте макрос «HTML», откройте файл в текстовом редакторе (Блокнот), скопируйте всё содержимое и вставьте в макрос. Порядок — как в таблице выше, сверху вниз.
Шаг 4. Нажмите «Сохранить» и проверьте страницу: вверху должна быть полоса навигации, текущая страница в ней выделена.

Содержимое файлов менять нельзя: каждый файл — самостоятельный блок.
