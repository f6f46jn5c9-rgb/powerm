4 ШАГА
1. Откройте страницу хаба и нажмите «Редактировать».
2. Откройте первый сверху HTML-макрос (дважды щёлкните по нему). Удалять остальные макросы не нужно.
3. Выделите всё содержимое макроса и замените его: откройте файл 1-hub-shapka-knopki.html в Блокноте, Ctrl+A, Ctrl+C, вставьте в макрос (Ctrl+V).
4. Нажмите «Сохранить» в макросе, затем «Опубликовать» на странице. Проверьте: под текстом шапки две индиговые кнопки.
