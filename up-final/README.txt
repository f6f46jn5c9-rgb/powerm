КАК ЗАМЕНИТЬ СОДЕРЖИМОЕ СТРАНИЦЫ
Шаг 1. Откройте страницу «Управление проектами» в Confluence и нажмите «Редактировать».
Шаг 2. Удалите старый макрос HTML (выделите макрос, нажмите Delete).
Шаг 3. Вставьте макрос HTML и целиком скопируйте в него содержимое файла 1-up-main.html.
Шаг 4. Нажмите «Опубликовать» (сохранить) и проверьте страницу.
