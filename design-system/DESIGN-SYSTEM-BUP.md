# Дизайн-система БУП · Силовые машины (для Claude Design)

> Вставьте целиком в поле инструкций дизайн-системы. Источник — реальный CSS репозитория (хабы БУП, карта проектов, проектный трек ДБВ, «Управление проектами»). Все значения взяты из кода, а не придуманы. Что я достроил сам для слайдов — помечено **[экстраполяция]**.

---

## 0. Суть стиля одной фразой

**iOS-чистота + тёмное «матовое стекло» с мягким цветным свечением.** Светлая белая страница, на ней — крупные скруглённые плитки-градиенты почти чёрного оттенка с одним цветным «световым пятном» в правом верхнем углу, поверх — полупрозрачное стекло с блюром и белой тонкой кромкой. Всё остальное (текст, таблицы, схемы) — спокойный редакционный стиль: системный шрифт, много воздуха, тонкие линии, один акцентный цвет.

Два режима, не смешивать на одном элементе:
1. **Витрина (hub / glass)** — плитки навигации, KPI-плашки, герой-блоки, диаграммы-ганты. Тёмный градиент + стекло + свечение.
2. **Редакция (track / editorial)** — инструкции, таблицы, этапы. Белый фон, тонкие линии, teal-акцент, красные ромбы «контрольных точек». Без теней и градиентов, кроме одной полосы.

Правило пропорции: **~85% страницы — белая и тихая, ~15% — тёмные стеклянные плитки.** Плитка — это событие, а не фон.

## 1. Токены

### Типографика
- Шрифт: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif` (на устройствах Apple — SF Pro; **веб-шрифты не подключать**). Для слайдов допускается Inter как ближайший аналог SF.
- Заголовок страницы H1: **800**, 30px (мобайл 24), line-height 1.15, `text-wrap: balance`. Цвет — градиентный текст (см. 2.2) или `#1a2a5e`.
- H2: 800, 26px / 1.25. H3: 700, 19px / 1.3.
- Текст: 400, 16px / 1.4 (мобайл 15). Вторичный: 14px, `--muted`.
- Эйброу / метка секции: **600, 11–13px, UPPERCASE, letter-spacing .06–.08em, `#5B6670`**.
- Цифры KPI: 22px / weight 500 (на слайдах — 56–96px, weight 700–800) **[экстраполяция размера]**.
- Акцент в заголовке: одно ключевое слово окрашено в акцентный цвет (`Инструкция по <teal>проектному треку</teal>`).
- Никаких переносов по слогам; `word-break: normal`.

### Общие нейтрали
| Токен | Значение |
|---|---|
| ink | `#1F2A33` |
| muted | `#5B6670` (на светлом), `#6b7280` (подзаголовки) |
| line | `#E3EAED` (разделители 1px), `#e7e9f0` (рамки карточек) |
| white | `#FFFFFF` |
| page-bg (инструкции) | `#f2f1ed` (тёплый серо-бежевый) — только для «документных» страниц; хабы на чисто белом |

### Форма и движение (iOS-ощущение)
- Радиусы: **плитки 16px**, панели 12px, герой-блок 12–16px, кнопки 10px, бейджи и пилюли 999px, иконки-кружки 50%.
- Тени всегда **окрашены в цвет темы и мягкие**: `0 10px 26px rgba(30,71,128,.30), 0 2px 6px rgba(26,42,94,.12)`; при hover `0 16px 32px rgba(30,71,128,.38)`.
- Hover плитки: `translateY(-3px)`, кромка стекла становится ярче (`.45 → .85` белого), стрелка сдвигается на 4px вправо.
- Появление: `opacity 0 + translateY(8px)` → норма, 0.45–0.5s ease, **каскад 45–60ms на элемент** (`animation-delay: calc(var(--i) * 45ms)`).
- Переходы: `.25s ease`. Всегда уважать `prefers-reduced-motion`.
- Фокус: контур 3px акцентного цвета, offset 3px.

## 2. Витрина: стекло + свечение

### 2.1 Рецепт плитки (главный компонент)
Три слоя в одной плитке: **fx** (цвет) → **glass** (стекло) → **контент**.

```css
.tile{position:relative;isolation:isolate;display:flex;flex-direction:column;justify-content:space-between;
  min-height:128px;padding:16px;border-radius:16px;color:#fff;
  box-shadow:0 10px 26px rgba(30,71,128,.30),0 2px 6px rgba(26,42,94,.12);
  transition:transform .25s ease,box-shadow .25s ease}
.tile:hover{transform:translateY(-3px);box-shadow:0 16px 32px rgba(30,71,128,.38)}

/* слой 1: цвет + «неоновое» световое пятно */
.tile__fx{position:absolute;inset:0;border-radius:inherit;overflow:hidden;z-index:0;
  background:
   radial-gradient(ellipse 55% 50% at 78% 18%, rgba(100,180,255,.88) 0%, transparent 65%),   /* пятно света сверху справа */
   radial-gradient(ellipse 35% 35% at 14% 82%, rgba(42,92,168,.52) 0%, transparent 65%),     /* подсветка снизу слева */
   linear-gradient(140deg,#040810 0%,#08102a 40%,#152048 72%,#2a5ca8 100%)}                  /* почти чёрная база */
.tile__fx::before{content:"";position:absolute;inset:-24px;filter:blur(8px);                 /* размытый «блум» */
  background:
   radial-gradient(circle at 88% 10%, rgba(96,176,255,.8) 0, transparent 42%),
   radial-gradient(circle at 8% 46%,  rgba(58,120,212,.7) 0, transparent 36%),
   radial-gradient(circle at 94% 40%, rgba(96,176,255,.45) 0, transparent 32%)}

/* слой 2: матовое стекло */
.tile__glass{position:absolute;inset:0;border-radius:inherit;overflow:hidden;z-index:1;
  background:
   linear-gradient(0deg, rgba(5,10,22,.88) 0, rgba(5,10,22,.5) 48%, rgba(5,10,22,0) 90%),    /* затемнение под текст */
   linear-gradient(rgba(255,255,255,.08),rgba(255,255,255,.08));                              /* молочная вуаль */
  -webkit-backdrop-filter:blur(14px) saturate(140%);backdrop-filter:blur(14px) saturate(140%);
  border:1px solid rgba(255,255,255,.45);                                                     /* кромка стекла */
  box-shadow:inset 0 1px 0 rgba(255,255,255,.6), inset 0 0 26px rgba(255,255,255,.14)}        /* блик сверху + внутреннее сияние */
.tile__glass::before{content:"";position:absolute;inset:-14px;
  background:linear-gradient(135deg,rgba(255,255,255,.3) 0,rgba(255,255,255,0) 42%)}          /* диагональный глянец */

/* слой 3 */
.tile__ico{width:48px;height:48px;border-radius:50%;border:1px solid rgba(255,255,255,.5);
  background:rgba(255,255,255,.18);box-shadow:inset 0 1px 0 rgba(255,255,255,.45)}             /* иконка в стеклянном кружке, линия 2px, белая */
.tile__name{font-weight:700;font-size:16px;line-height:1.2;color:#fff;text-shadow:0 1px 2px rgba(0,0,0,.3)}
```
Композиция плитки: сверху иконка-кружок слева и стрелка `→` справа, **название внизу слева**. Название ≤ 3 слов.
Fallback без backdrop-filter: поднять белую вуаль до `.16–.24`.
Состояние «Скоро»: opacity .6, без hover, вместо стрелки подпись «Скоро» (13px/600).

### 2.2 Герой-шапка страницы (hub header)
`←  БУП` (крошка, 13px, ссылка акцентного цвета) → строка: **иконка-кружок 56px** (градиент `135deg` акцент→тёмно-синий, тень `0 6px 16px rgba(26,42,94,.22)`, белая линейная иконка) + H1 (градиентный текст `135deg #1e4780 → #2a5ca8`) + подзаголовок 15px `#6b7280` → под ними **градиентная линия 5px**, исчезающая вправо: `linear-gradient(90deg,#1e4780,#2a5ca8 35%,#60b0ff 70%,rgba(96,176,255,0))`.
Вариант «тёмный герой» (внутренние страницы): та же `fx`-заливка на весь блок, радиус 12px, паддинг 24×32, белый H1 22px/700, белая крошка с opacity .65.

### 2.3 Палитры тем (меняется только цвет, структура одна)
Формат: `[пятно, подсветка] + база 140°`. Тему выбирает раздел, внутри раздела цвет не менять.

| Тема (раздел) | Пятно | Подсветка | База (0% → 40% → 72% → 100%) | Акцент текста/линии |
|---|---|---|---|---|
| **Синяя** (БУП, БССМ — по умолчанию) | `rgba(100,180,255,.88)` | `rgba(42,92,168,.52)` | `#040810 #08102a #152048 #2a5ca8` | `#2a5ca8`, заголовок `#1a2a5e` |
| **Бирюзовая** (Производство) | `rgba(63,194,180,.85)` | `rgba(14,124,123,.5)` | `#040d0d #071a1a #0a3030 #0e7c7b` | `#0e7c7b` / `#0a5f5e`, линия до `#35b8b3` |
| **Графит** (Инжиниринг, ОТ, ИЗМ) | белёсое `rgba(255,255,255,.45)` | серо-стальное | `#0a0c0d #151d20 #243038 #546e7a` | `#546e7a` |
| **Фиолетовая** (Сбыт и сервис) | `rgba(170,130,200,.72)` | `rgba(58,42,64,.55)` | `#060406 #0f0b10 #1d1520 #3a2a40` | `#3a2a40` |
| **Оранжевая** (Внешние) | `rgba(255,180,100,.88)` | `rgba(196,94,26,.52)` | `#100803 #1f1008 #4a2410 #c45e1a` | `#c45e1a` |
| **Зелёная** (Закупки) | `rgba(100,200,140,.88)` | `rgba(45,106,79,.52)` | `#040d08 #071a0f #0f3020 #2d6a4f` | `#2d6a4f` |
| **Тёмно-синяя** (Чемпионат) | `rgba(90,140,230,.60)` | `rgba(27,61,122,.55)` | `#03060c #070f1f #0e1f3d #1b3d7a` | `#1b3d7a` |
| **Малиновая** (голосование — «горячая» плитка, один акцент среди синих) | `rgba(255,110,150,.70)` | `rgba(220,50,90,.50)` | `#14030a #3a0a1c #7a1636 #b01e4e` | `#b01e4e` |
| **HR** | — | — | акцент `#4a6cb7` / тёмный `#3a5ba0` | линия до `#7a9fd4` |

Правило: одна «горячая» плитка (малиновая) на экран допустима как призыв к действию; больше — нет.

### 2.4 KPI-плашки
Тёмный градиент без стекла: `radial-gradient(ellipse 60% 70% at 85% 10%, rgba(100,180,255,.45) 0, transparent 70%), linear-gradient(140deg,#040810,#08102a 40%,#152048 72%,#2a5ca8)`, радиус 6px (на слайдах 16px **[экстраполяция]**), паддинг 12×14. Число 22px/500 белое, подпись 12px `#dbe6f7`. Ряд из 4, gap 10px; на узком — 2×2.

## 3. Инфографика и визуализация

### 3.1 Таймлайн / гант (карта проектов)
Сетка: колонка подписей 160px + N равных колонок по году, gap 3px, строка высотой 30px. Бар — **вертикальный градиент `тёмный → средний`** (`linear-gradient(180deg,var(--c),var(--d))`) + **верхняя «кромка света» 2px** светлого тона (`border-top:2px solid var(--t)`), крайние бары скруглены 5px. Подписи строк 12px `#5B6670`, годы 11px по центру. Легенда: квадрат 11px r3 с тем же градиентом + подпись 11px. Разделители — 0.5px `#E3EAED`.

Палитра рядов (тёмный / средний / светлая кромка):
Мини-Т `#1a2a5e #2a5ca8 #60b0ff` · СМ 2.0 `#0b4f6c #1596b8 #7fdcf5` · СМ 3.0 `#2d1b69 #6a4fc4 #b9a6ff` · Ворота качества `#2c1c1c #80564c #d4ada2` · Закупки `#1d4a22 #4a9d3a #a8e08a` · Фабрика результатов `#5a0d3a #c2276f #ff8cc0`.
Правило: ряд = один цвет-тройка, не больше 6–7 рядов, цвет закреплён за сущностью по всему документу.

### 3.2 Роадмап / путь проекта (редакционный режим)
Горизонтальная линия 2px `#00A8C0`; на ней **узлы-кружки 44px** (белая заливка, обводка 2px `#007890`, номер «Э1…Э5» 700). Выбранный узел — залит `#007890`, текст белый. Между узлами — **красные ромбы «КТ1…КТ5»** (44px, `#E01828`, белая подпись 12px/700) = контрольные точки. В конце — маленький узел «возврат цикла» (иконка круговой стрелки). Подписи этапов под узлами 15px/700, `text-wrap:balance`. Под схемой — панель деталей выбранного узла (3.5). На узком экране линия становится вертикальной.

### 3.3 Светофор / статусы
Статус — **цветная точка 10px + текст 600**, а не залитая плашка. Зелёный `#2d6a4f`/`#0e7c4a`, жёлтый/оранжевый `#c05c00`, красный `#E01828`, серый `#5B6670`. Мини-прогресс: полоска 3–4px `#E3EAED`, заливка `#00A8C0`/`#007890`, r2.

### 3.4 Цепочки и процессы
Узлы текстом, соединённые стрелкой `→` (teal, stroke 2px); под узлом — серая подпись 13px (что делает шаг). Шаги — нумерованные кружки: градиент `135deg #0a5f5e → #0e7c7b`, 26–32px, белое число 700. Для нескольких параллельных потоков — «дорожки» с тонкой линией-разделителем.

### 3.5 Панель деталей и выноски
- **Панель** `.panel`: белая, рамка 1px `#E3EAED`, **левая полоса 3px `#007890`**, радиус 12px, паддинг 18×22.
- **Ключевое** (key/note): фон `#EEF9FB`, левая полоса 3px `#007890`, без скруглений.
- **Критичное** (warn): фон `#FDF1F2`, левая полоса 3px `#E01828`, метка жирным `#D61525`.
- В документных страницах: tip `#e6f4f3` + `#0e7c7b`, warn `#fff8f0` + `#c05c00`, ok `#f0faf5` + `#0e7c4a`; иконка 16px линейная слева.
- Правило: плашка — только для 1–2 действительно важных мыслей на экран.

### 3.6 Таблицы
Без зебры и вертикальных линий. Шапка: 13px/600 `#5B6670`, **нижняя линия 2px `#007890`** (на документных страницах — шапка `#e6f4f3` с teal-текстом). Строки: 15px, разделитель 1px `#E3EAED`, вертикальный паддинг 7px, первая колонка — номер teal 700 или название 600. Выбранная строка — фон `#EEF9FB`. «Определение-список» (термин слева 14px/600 muted, значение справа 16px) — для карточек этапов. На мобайле таблица превращается в карточки с подписью поля сверху (`data-label`, 11–13px uppercase).

### 3.7 Матрица ролей / легенда
Маркеры 14px: ромб красный (решает), круг teal залитый (исполняет), круг teal контур (участвует/согласует), серая «i» (информируется). Легенда в строку над таблицей, 14px muted. Фильтр — чекбокс с `accent-color:#007890`.

### 3.8 Списки результатов
Строка: номер `01` (teal, 13px/700) · заголовок-ссылка (teal 700, подчёркнутый) · описание 14px · **справа большая метрика** (24px/800 teal, «67% → 33%») с подписью 12px muted. Строки разделены тонкой линией.

### 3.9 Кнопки, вкладки, бейджи
- Кнопка вторичная: белая, рамка 1px teal, текст teal 600, радиус 10px, паддинг 8×14, справа стрелка `→`; hover — фон `#EEF9FB`.
- **Стеклянная кнопка (индиго)**: `background:rgba(42,58,140,.84);backdrop-filter:blur(8px) saturate(120%);border:1px solid rgba(255,255,255,.28);border-radius:10px;box-shadow:inset 0 1px 0 rgba(255,255,255,.18);color:#fff;font:600 15px/1.35;min-height:44px;padding:12px 20px`.
- Вкладки: текст 14px, активная — teal 700 + **подчёркивание 3px** (не пилюля).
- Бейдж: пилюля 999px, 12px/600, фон `rgba(255,255,255,.7)` + blur 14px + рамка `rgba(14,124,123,.3)`.
- Ссылки в тексте: teal `#007890`, подчёркнуты 1px, offset 2px.

### 3.10 Фото людей (эксперты, кураторы)
Круг 64–72px, фото крупным планом, подпись справа: ФИО 16px/700 navy `#1a2a5e`, роль 14px muted, e-mail teal. Сетка 3 колонки.

## 4. Композиция страницы
- Контентная ширина 1000–1100px; сетка плиток **3 колонки → 2 → 1** (брейкпоинты 900 / 700px по ширине контейнера, а не окна). Gap 14px. Ряды могут чередоваться 3 + 2 (последняя плитка в ряду растягивается).
- Порядок: крошка → герой → (метка секции uppercase) → плитки → разделитель 1px `#E3EAED` → следующая секция.
- Секции разделяются воздухом 24–32px, а не рамками. Карточек-в-карточках нет.
- Заголовок секции в витрине — только метка UPPERCASE 13px/600 `#6b7280`.

---

## 5. Иконки
Линейные, **stroke 1.7–2px, round cap/join**, без заливки, белые на тёмном, teal на светлом, 16–24px; набор в духе SF Symbols / Lucide (слои, флаг, цикл, ромб, воронка, гаечный ключ, шестерня, кубок, график). В стеклянном кружке 48px, обводка кружка `1px rgba(255,255,255,.5)`.

## 6. Применение к презентациям **[экстраполяция — в репозитории слайдов нет]**
- Фон слайда: белый (`#fff`) для содержательных, **тёмный `fx`-градиент выбранной темы** — для титула, разделителей и итогового слайда. Не больше 1 тёмного слайда на 3–4 светлых.
- Титул: тёмный градиент во весь слайд, слева вверху иконка-кружок в стекле, H1 белый 56–72px/800, под ним градиентная линия 5px, внизу мелкая метка UPPERCASE `СИЛОВЫЕ МАШИНЫ · ПРОГРАММА`.
- Контентный слайд: крошка/метка секции сверху, H2 800 с одним акцентным словом, ниже **не больше одной** стеклянной сцены (3 плитки или 4 KPI) либо одна схема/таблица.
- KPI-слайд: 3–4 тёмные плашки с числом 64–96px и подписью; сравнение «было → стало» через `→` и акцентный цвет у результата.
- Схема процесса: роадмап по 3.2 (кружки + ромбы-КТ), не более 5–7 узлов.
- Диаграммы: гант по 3.1, столбцы — вертикальный градиент `тёмный → средний` + светлая верхняя кромка, подписи значений над столбцами, без сетки и осей-рамок.
- Одна идея на слайд, ≤ 30 слов основного текста, заголовок — вывод, а не тема.

## 7. Чего НЕ делать
- Не использовать чистый `#000` и плоские насыщенные заливки: база всегда «почти чёрная с оттенком» + свечение.
- Не ставить стекло на белый фон без цветного слоя под ним — стекло видно только над `fx`.
- Не смешивать темы (синяя + оранжевая плитки) в одном ряду; исключение — одна «горячая» малиновая.
- Не заливать плашки цветом в таблицах/статусах: цвет статуса = точка рядом с текстом.
- Не рисовать тени чёрными; тень — цвет темы, 20–38% непрозрачности.
- Не использовать эмодзи и декоративные картинки; иконки линейные, фото — реальные люди.
- Не использовать красный как «декор»: красный — только контрольные точки, критичные предупреждения и одна горячая плитка.
- Нет жирных рамок и зебры; разделяет тонкая линия `#E3EAED`.

## 8. Тон текста
Русский, деловой, коротко, глаголами. Метки — существительными. Расшифровывать аббревиатуры при первом упоминании (КТ — контрольная точка, ПЗ — «Полярная звезда», ДБВ — «Достичь большего вместе»). Названия разделов — без точки; заголовок страницы может иметь форму «Раздел. Силовые машины».
